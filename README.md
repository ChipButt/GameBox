# GameBox

A mobile-first browser games hub.

## Included games

### House Rules
- 1–4 players
- 54-card deck including red and black jokers
- Assign rules to each card rank and both jokers
- Separate Setup and Game Play modes
- Save and load named card-game presets in the browser
- Turn tracking, draw history, and Shuffle & Restart

### Coin Flip
- 1–4 players
- Set a custom number of coins for each player
- Automatic total coins per round
- Turn-based multi-coin flipping
- Heads/tails totals and recent-flip history
- Save and load named coin-game presets

## Mobile first
The interface is designed for phones first, with large touch targets, single-column play layouts on small screens, and sticky primary game actions.

## Run
Open `index.html` in a browser. No backend, account, API key, or external library is required. Saved setups use browser `localStorage`, so they remain on that browser/device.
